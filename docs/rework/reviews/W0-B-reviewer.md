## Round 1 — FAIL (superseded)

Replay is genuinely lossless and recording genuinely non-perturbing. The **outcome** half is not: 10.7% of outcomes report deltas their own window cannot produce, every scaffold block is sampled at answer time (so rows claim interventions that had not happened yet), and two paths drop rows with no counter and no error.

## Defects

**D1 — FAIL. Outcome deltas are sampled at the NEXT think, not at `closedTick`.** `OutcomeTracker.close()` (`record/OutcomeTracker.ts:225`) only stamps tick+reason; everything else is read in `finalize()` (`:234–276`), which runs when the being's *next* act arrives (`:103`) or at `flush()`: `needDeltas` `:269`, `healthDelta` `:270`, `knowledgeFormed/Changed` `:249–253`, `aliveAtEnd` `:273` all read `world.body/knowledge(beingId)` **now**. A plan finishing in 1 tick and re-thinking 2,000 ticks later reports those 2,000 ticks as its own result; a dead being is finalized only at `flush()`, so its deltas run to the end of the run.
*Repro:* 50 beings × 4,000 ticks, reflex-policy mock, window 400 → **188/1757 outcomes (10.7%)** carry a |hunger delta| past the physical budget (0.15/tick·span + 1); worst = window `3380→3380` (**0 ticks**, `planCompleted`) reporting `hungerDelta −51.74`, 51.7× possible. This is the reward signal the whole rework exists for.

**D2 — FAIL. `scaffold` is captured at answer time; future interventions are claimed as present.** `CognitionRecorder.complete()` (`record/CognitionRecorder.ts:149–157`) calls `scaffold.beingState(...)` and `world.carriesNarrative(...)` when the answer lands. `ScaffoldLedger.beingState` `:117` clamps with `Math.max(0, tick - at)`, so an intervention *after* the prompt tick reports `0` — the strongest possible value — not `null`; `:122` filters seeded myths by what the being carries **now**; `:123` returns `authoredEvents` unfiltered by tick. Exact sibling of the `thinkInput` bug already fixed.
*Repro:* slow backend, prompt built at tick 14, every intervention at tick ≥ 135 → the row reads `{needsProvisionedWithinTicks:0, itemsGrantedWithinTicks:0, relocatedWithinTicks:0, seededMyths:["seed:myth"], authoredEvents:[{tick:135,…}], seededRecipes:["spear"], ideasGiven:1}` with its own `tick:14`; `authoredEvents[0].tick > record.tick` is self-evidently impossible. Poisons every `ScaffoldCounts` field in `summarizeCorpus` (`training/summarize.ts:122–137` tests `!== null`) — audit-03 §8 item 8's acceptance criterion.

**D3 — FAIL. A think in flight at `endRecording()` is applied to the world and silently not recorded.** `complete()` `:115` `if (!attempt || !input || this.closed) return;` — no counter, no warning. `SessionManager.finish()` (`packages/mcp/src/SessionManager.ts:145`) calls `endRecording()` in exactly that position while the scheduler callback still runs `applyPlan` (`runner/Experiment.ts:573–596`).
*Repro:* 1 pending think at close → `cognitionLog.count=1`, `sink.records=0`, `summary.cognitionCount=0`, body plan afterwards `["Idle"]` — the world acted on a think that has no row anywhere.

**D4 — FAIL. A throwing sink loses rows, inflates the manifest, orphans outcomes.** `complete()` runs `tracker.beginAct` + `cognitionCount++` (`:161–162`) **before** `sink.cognition(record)` (`:163`), and `CognitionScheduler.pump` (`scheduler/CognitionScheduler.ts:54–58`) turns a throw from `job.apply` into an unhandled rejection it swallows.
*Repro:* sink throws `ENOSPC` from row 6 → 5 rows on disk, `summary.cognitionCount=69`, 64 orphan outcomes, 64 unhandled rejections, sim unaffected. The file sink itself throws correctly (`EISDIR` verified) — the caller eats it.

**D5 — HIGH. Retried rows pair the accepted completion with a prompt that did not produce it.** `LlmMind.complete` re-calls `backend.complete(input, lastError)`; `FireworksMindBackend.ts:49–51` appends `"Your previous reply was rejected: …"` to `prompt.user`. The record keeps only the first-attempt prompt (`LlmMind.ts:131–132`) while `acceptedCompletion` takes the **last** attempt (`training/corpus.ts:34–39`) and `cognitionToExample` `:48` accepts `retried:true`. §8 item 1 ("replay into a byte-identical prompt") fails for exactly those rows and the fine-tune target is mis-paired. *Repro:* backend saw `retryError="not valid JSON"`; `prompt.user` has no retry suffix.

**D6 — MED.** `latencyMs` is wall clock *inside the row*, so identical seeded runs produce different corpus bytes (`latA=[0.718,1.144,…]` vs `latB=[0.363,1.026,…]`, 24 rows each): no dataset hash over `cognition.jsonl` is reproducible. **D7 — MED. "unscaffolded" guarantees nothing** — still public and unledgered: `agentBody(id)` → `needs.*`/`health`/`sickUntil`/`inventory[*]`/`plan`; `exp.bus.emit(...)`; `agentEntity(id).components['Transform2D']` (also skips `spatial.markMoved`); `minds.get(id).{knowledge.applyEvidence, narratives.seed/remember, relationships.gainRespect, memory, goals, injectIdea}`; `exp.conscious.add(id)`; `exp.body.setPlan(...)`. Nine `packages/mcp/_phase2_exp*.mjs` drivers still use all of them verbatim.

**Nits.** NaN/Infinity in a `ThinkInput` becomes `null` and `buildThinkPrompt` then *throws* on replay (`consciousness/prompt.ts:157`); `deserializeThinkInput` validates nothing. `-0` → `0`. `outcomeLinkedRate` is `linkedOutcomes / records` (`summarize.ts:188`) — can exceed 1 if ids repeat (0 repeats in 2,138 rows). `record.tick` is the prompt tick but `outcome.openedTick` uses post-increment `this.tick` (`Experiment.ts:527` vs `:594`) — constant +1 skew. Two sinks on one runId silently merge. An `interrupted` window stops recording speech (`OutcomeTracker.ts:154,180`), so `spoken:false` there means "unknown", not "not spoken".

## Backlog (none blocking)

1. **`closeRun` throw is fully silent** — `CognitionRecorder.end():222–233` catches it outside `guard`, so `onFailure` never fires and `failureReason` stays `null`. Rows and outcomes are all durable and reconcilable, but the host is never told the manifest is missing and the run just looks unfinished. Smallest real gap; a one-line `onFailure` call fixes it.
2. **Retry stale base** — `LlmMind` stores `retryPrompt(promptBuiltAtT0, feedback)` while a backend composes `retryPrompt(buildThinkPrompt(liveInput), feedback)`. If the live `ThinkInput` mutates between attempts they diverge (proven with a mutating input). Fix properly by passing the composed prompt to `IMindBackend` instead of letting it rebuild.
3. **`latencyMs` irreproducible bytes** — accept as documented; hash the corpus with the field excluded, or move it to a side file so the dataset hash is over the row itself.
4. **Unledgered public mutation surface** — unchanged. Ship it, but rename the card's `scaffold.unscaffolded` to something like `noRecordedIntervention`: it means "no sanctioned intervention was logged", not "the being was on its own", and the nine `_phase2_exp*.mjs` drivers still bypass the ledger entirely.
5. **Row size** — 15.8 KB/row → **20.4 KB/row**, because every attempt stores a full prompt copy and a retried row duplicates the ~4 KB base. Store the retry as a suffix/delta.
6. `makeConscious` re-reports already-conscious beings as newly made (the tool announces "made 7 conscious" for a no-op); the ledger is not fooled. A concurrent second `finish()` rejects rather than no-op'ing — safe, but noisy over MCP.
7. Carried from Round 1, all agreed backlog: NaN/Infinity → `null` makes replay throw (`prompt.ts:157`) with no validation in `deserializeThinkInput`; `-0` → `0`; `outcomeLinkedRate` can exceed 1 if ids repeat (0 repeats in 1,866 rows this round); two sinks on one runId silently merge; an `interrupted` window stops recording speech, so `spoken:false` means "unknown" — add an explicit `speechTrackingStopped` flag rather than leaving it inferred.
