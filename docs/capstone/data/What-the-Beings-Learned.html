What the Beings Learned

Two runs of 100 simulated beings over 20 days (48,000 ticks), with an LLM slow mind (gpt-oss-120b) and deterministic learning. Nobody wrote the rules below — the beings mined them from what happened to them.

Sources: research.db (events, knowledge_snapshots, metrics), corpus/civilization.jsonl, one recorded cognition row (thinkInputRows.c727af7.json), report phase3-exp1-apprenticeship.md.

Knowledge grows from nothing

Every being starts knowing nothing. Rules appear as experience accumulates and spread by sharing. The two runs use the same seed; the only difference is whether watching a craft can teach it.

Beliefs form, get tested, and die

A belief enters as a hypothesis, becomes held when the world keeps confirming it, is contested when evidence conflicts, and is abandoned when it stops holding up. Run 2, day 20 — 10,113 belief records across 123 beings.

Source: knowledge_snapshots.status. False beliefs are allowed by design; they are measured, not prevented.

The rules nobody wrote

The fourteen rules held by the most beings at day 20 (run 2), with the share of the population holding each and the average confidence. Each was mined from the being's own events by a deterministic learner.

Rule keys: out: an action's effect on a need · ctx: the context an event happens in · seq: a learned action sequence. Source: knowledge_snapshots, status = held, tick 48,000.

Apprenticeship: one maker becomes 168

One founder was seeded with the spear recipe; everyone else began ignorant. With observation learning on, children near a maker watch, learn and are watched in turn. With it off, the recipe dies with the founder.

What a being sees when it thinks

This is a real recorded prompt: being 1829 at tick 184, early in its life. Everything the model receives is built from the being's own state. There is no description of the world it could cheat from, and it may answer with goals, plans and speech — never facts.

What came out: the thought corpus

2,119 recorded thoughts from the June experiments — each with the being's reasoning, what it said, and the plan it chose. This is the data the first fine-tune was trained on.

A world in events

The twelve most frequent event types in run 2. Speech dominates; the second line is the world refusing an intent — a being asking for something its world does not allow, which it then remembers.

Source: events.type, run 2, 146,950 events over both runs.
